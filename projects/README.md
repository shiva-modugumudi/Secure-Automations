# SOC Automation Projects

This directory will contain practical SOC automation projects as they are defined and implemented.

Create a descriptive folder for each project, such as `alert-enrichment`, once its scope is agreed. Keep its code, README, and sanitized examples together. Add dependencies and meaningful validation appropriate to the implementation.

Use the [project documentation guide](../docs/project-guide.md) to describe the problem, setup, usage, results, and limitations.
